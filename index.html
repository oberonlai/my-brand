// 關於我

Oberon Lai

codotx 想點創意科技的主理人。日常有兩件事：一件是把客戶想要的功能，寫成穩定好維護的 WordPress 外掛；另一件是把網站翻過來看，找出那些平常沒事、但被人試一下就會出事的地方。

我偏好把事情講清楚再動手：需求先對齊、範圍先講明、程式碼寫得讓下一個接手的人看得懂。技術文章也是同一件事的延伸——把踩過的坑寫下來，讓遇到同樣問題的人少繞一圈。

  • 專長WordPress 外掛開發、PHP、資安弱點檢測與修補
  • 寫作技術部落格，記錄開發與資安的實作經驗
  • 經歷細節（待補：學經歷與服務年資，等真實資料再補上）

// 服務項目

我能幫你做的三件事

不確定自己需要哪一項也沒關係，來信描述現況，我會直接告訴你該從哪裡開始。

開發

WordPress 外掛開發與客製

依你的流程開發專屬功能，或改造既有外掛。交付前做過測試，交付後留得住維護，不是寫完就跑。

  • 需求釐清與可行性評估
  • 後台介面、REST API、金流與第三方串接
  • 版本更新與長期維護

資安

網站資安弱點檢測與修補

檢查外掛與佈景主題有沒有常見的可利用弱點，找到之後附上重現方式與修補寫法，不只丟一份掃描報告給你。

  • 輸入過濾、權限與 nonce 檢查
  • SQL 注入、XSS、越權存取等常見弱點
  • 修補建議與回歸驗證

顧問

技術顧問與知識分享

團隊裡沒有熟 WordPress 的人時，我可以當那個問得到答案的人：程式碼審查、架構討論、內訓分享。

  • 程式碼審查與重構建議
  • 開發規範與流程建立
  • 教育訓練與技術文章撰寫

// 合作方式

從第一封信到上線，會經過這四步

  1. 01

    來信說明現況

    你把想解決的問題、網站網址與期望時程寫給我，愈具體愈好，不用先想好技術怎麼做。

  2. 02

    釐清範圍與報價

    我會回問幾個關鍵問題，確認範圍後給你做法、時程與費用，講清楚哪些包含、哪些不包含。

  3. 03

    開發或檢測

    過程中固定回報進度，有變動先講。資安案件則會附上弱點說明與重現步驟。

  4. 04

    交付與後續維護

    交付含說明文件，上線後保固期內修正問題，也可以轉成包月維護長期合作。
